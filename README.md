# Lumen

A hands-on learning project exploring **LangChain**, **Retrieval-Augmented Generation (RAG)**, **embeddings**, **vector databases**, and **FastAPI**.

## About

Lumen is a practical project built to understand and experiment with modern AI application components.  
It focuses on combining document retrieval with large language models to create more accurate and context-aware responses.

## Technologies

- LangChain
- RAG (Retrieval-Augmented Generation)
- Embeddings
- Vector Databases
- FastAPI
